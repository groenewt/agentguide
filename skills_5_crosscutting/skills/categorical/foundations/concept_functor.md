# Concept: Functor — Structure-Preserving Map
## F:C→D. Object map A↦F(A). Morphism map f↦F(f). Preserves: F(g∘f)=F(g)∘F(f), F(id)=id.
## Properties: Faithful (injective on Hom), Full (surjective on Hom), Equivalence (Full+Faithful+Ess.Surj).
## Sources: Mac Lane (1971) Ch.I§3; Riehl (2016) Def 1.3.1.
