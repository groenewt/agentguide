# Concept: Functorial Data Migration — Δ,Σ,Π
## Given F:C→D: Δ_F (pullback/restrict), Σ_F (left Kan/union), Π_F (right Kan/product).
## Adjoint triple: Σ⊣Δ⊣Π. Parameterizes ALL database ops categorically.
## Federation: span A←C→B, migrate via Σ_G∘Δ_F. No shared upper ontology needed.
